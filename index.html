          01
          
Obstacle Avoiding Robot

          ★ HARDWARE
        

        
Autonomous robot firmware using HC-SR04 ultrasonic sensors and L298N motor-driver
        logic for real-time obstacle detection and navigation. My first full loop: sense → decide → act — in silicon.

        
C++ArduinoUltrasonicMotor DriverEmbedded

        

          Technical Breakdown ▾
          

            
▍The problem
Fixed-path robots die the moment the room changes. I wanted a machine that reacts to a world it can't predict.

            
▍The build
HC-SR04 pulse-timing for distance, threshold logic on the MCU, and L298N dual H-bridge control for differential steering — tuned in C++ on Arduino.

            
▍The result
A robot that navigates live obstacles autonomously — and a maker who finally understood interrupts, timing, and why datasheets matter.
